# Arevalo Dental Clinic Website

## Project Overview
A specialized bilingual medical platform bridging communication between Filipino medical professionals and Arabic-speaking patients in Gulf regions. The website provides dental services information, dentist profiles, and appointment booking capabilities with full English/Arabic language support and RTL functionality.

## Technologies
- Frontend: React + TypeScript + Vite
- Styling: TailwindCSS + shadcn/ui components
- Backend: Express.js + in-memory storage
- Internationalization: i18next with English/Arabic support
- Animations: Framer Motion
- Icons: Lucide React + React Icons

## Project Architecture
- **Client-side routing**: Wouter for SPA navigation
- **Component structure**: Modular components in /client/src/components/
- **Pages**: Home, Services, Doctors, Contact with appointment form
- **Multilingual**: Context-based language switching with RTL support
- **Storage**: In-memory storage for appointments and messages
- **API**: RESTful endpoints for form submissions
